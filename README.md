# WorkBuddy 多账号自动签到（带图形面板）

一个可双击打开的签到面板 + 命令行引擎，**不用在客户端里退出/切换账号**，
就能为所有登录过的 WorkBuddy 账号领取每日签到积分与成长中心奖励。

> ⚠️ **先读这段（风险与合规）**
> - 本工具通过逆向 WorkBuddy 桌面端接口实现代签，**不是官方功能**。
> - 使用第三方脚本操作账号存在**被风控/限制**的可能，尺度不透明。
> - 请自行判断是否使用；建议只用于自己本人拥有的账号。
> - 本工具**不上传任何数据到第三方**，token 只在本机使用（见「凭据安全」）。

---

## 一、它能做什么

- **免切换账号**：客户端里登录过的每个号，都能被自动签到（靠客户端自己留的凭据归档）
- **图形面板**：双击打开，实时看每个号的签到结果；可添加账号、停用账号
- **可选定时**：想让它在每天固定时间自动跑也行（面板里勾一下）
- **只适用国内站**（www.workbuddy.cn）；国际版账号不适用

## 二、开始前的准备

1. **装 WorkBuddy 桌面客户端**，并**至少登录过一次**你要签到的账号
   （客户端每次登录都会在本地留一份凭据归档，脚本就靠这个免切换）
2. **装 Python 3**（python.org 的完整安装，**勾上 "Add python.exe to PATH"**）
   - 面板需要带 tkinter 的 Python；python.org 的安装包默认就带
   - 如已装过但不确定，直接双击启动器，它会自己找一个能用的

> 说明：如果你的系统里一个可用 Python 都找不到，启动时会弹一个提示框告诉你怎么装。

## 三、怎么用

### 图形面板（推荐）

双击目录里的 **`启动面板.bat`**。窗口打开后：

| 按钮 | 作用 |
|---|---|
| 立即签到 | 马上跑一轮：给所有启用的账号签到 + 成长中心 |
| 刷新状态 | 只查询、不领取（看连签天数和剩余积分） |
| 添加账号 | 扫描本机客户端里留过的账号，给它起名字纳管 |
| 创建桌面快捷方式 | 在桌面放一个图标，以后不用每次都来这个目录双击 |
| 打开日志文件 | 看完整历史记录 |

- **打开时自动补签**：默认勾选——开窗顺手把当天没签的补上，不想要就取消
- **每天定时自动启动**：勾上并填时间（如 `09:00`），到点自动开面板签到；
  可在面板里随时关掉。**这不是开机自启**，只有勾了多少跑多少
- **定时启动签完自动关窗**：让定时那一轮签完就退，不占着桌面
- 表格里**右键**某个账号：重命名 / 停用启用 / 移出列表

### 命令行（可选）

```powershell
cd <解压目录>

python run_all.py --list             # 看发现了哪些账号（不发请求）
python run_all.py --action status    # 只查询不领取
python run_all.py --verbose          # 立即跑一轮，屏幕上看结果
```

### 想完全静默（不开面板）？

```powershell
powershell -ExecutionPolicy Bypass -File .\install-tasks.ps1
```

注册两个后台计划任务（每天 00:05 + 每天 6 次轮询补签），不需要开面板。
卸载：

```powershell
Unregister-ScheduledTask -TaskName "WorkBuddySigninMulti" -Confirm:$false
Unregister-ScheduledTask -TaskName "WorkBuddySigninMultiPoll" -Confirm:$false
```

## 四、凭据安全

- **当前登录的号**：只**读取**客户端写出的凭据文件，绝不修改
  （避免和客户端抢刷新导致掉登录）
- **其它号**：用其 refreshToken 换一套新令牌，以 **DPAPI 加密**
  （Windows 数据保护，仅本机本用户可解密）存到 `state\` 目录
- **不打印、不上传 token**；日志里只有结果和积分数字
- 换电脑后 `state\` 里的旧凭据解不开，属正常——在新机器上让客户端登录一次即可

## 五、常见问题

**Q：面板打开了但表格是空的？**
A：说明本机还没有客户端登录过的凭据归档。先在 WorkBuddy 客户端登录一次那
个账号，重新打开面板即可。

**Q：添加账号时提示"没有发现新账号"？**
A：全新账号需要先在客户端登录它一次（产生归档），再点「添加账号」。

**Q：双击 `启动面板.bat` 闪一下就没了？**
A：大概率是没装 Python 或没勾 PATH。右键用 PowerShell 运行它可看到提示；
也可以从 python.org 重装一次 Python 并勾上 "Add python.exe to PATH"。

**Q：某个号长期不签，会不会失效？**
A：自持凭据会在临近过期时自动续期（约 50 天周期）。如果超过这个窗口一直
没用，需要你在客户端重新登录它一次。

**Q：每天定时为什么有时没跑？**
A：定时任务依赖系统电源状态。勾了「签完自动关窗」的会话如果到点时电脑在
睡眠，会等下次唤醒后排一条（任务带 StartWhenAvailable）。

## 六、目录内容

| 文件 | 说明 |
|---|---|
| `启动面板.bat` | 双击这个 → 打开图形面板（自动找 Python） |
| `panel.pyw` | 面板程序本体 |
| `run_all.py` | 引擎：发现账号 → 续期 → 逐个签到 → 写日志 |

| `LICENSE` | 上游 MIT 许可证 |
| `panel.json`、`accounts.json`、`state\`、`signin.log` | **首次运行后自动生成**（配置/凭据/日志） |
